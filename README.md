# 🎬 Watch Party Application

A full-stack web application that allows users to create virtual rooms and watch synchronized videos together in real-time. Built with a modern React frontend and a robust Spring Boot backend.

---

## 🚀 Features

* **User Authentication:** Secure user signup, login, and access control powered by Spring Security and JWT.
* **Real-Time Synchronized Rooms:** Host or join private/public watch rooms to watch video content simultaneously with friends.
* **Interactive UI:** Built with React for a fast, responsive, and intuitive user experience.
* **Backend Security & REST APIs:** Configured Spring Boot API endpoints handling user registration, authentication, and room session management.

---

## 🛠️ Tech Stack

### **Frontend**
* **Framework:** React.js (Vite)
* **Routing & UI:** React Router, CSS3 / Tailwind CSS
* **Package Manager:** npm

### **Backend**
* **Framework:** Java, Spring Boot
* **Security:** Spring Security, JWT (JSON Web Tokens)
* **Database:** MySQL
* **Build Tool:** Maven
